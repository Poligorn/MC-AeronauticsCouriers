# Changelog

Формат: дата · кратко что изменилось для игроков и пакмейкеров.

## Unreleased

- Планшет: новая рисованная рамка 84×84 (nine-slice 14 px). Java не менялся.
- Стажировка: `trainee_max_distance` по умолчанию 1500 (потолок ранга I; 0 = без лимита). Генератор NPC реально предпочитает короткие пары: сначала тасует, потом стабильно сортирует.
- Деревни: в каждой **новой** деревне (plains / desert / savanna / snowy / taiga) ровно одна почтовая станция у центра. Уже сгенерированные деревни не меняются.

## 0.3.0 (31.10.2026)

Релиз поверх `0.2.1-beta`. Протокол сети `PROTOCOL_VERSION` `"3"` → `"4"` (`BoardEntry.expensive`, `rareItemIndex`). Клиент и сервер должны быть одной сборки.

- Деревенские заказы: M/L/XL, дорогие и редкие появляются в обычной генерации станции, не только в `corkQa`. Размер бросается по тиру репутации и политике доски; на доске остаётся минимум один S ([PR #74](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/74)).
- Грузовые контейнеры: металлические текстуры E2 без дверей и табличек; единственная наклейка — накладная. XL — свои атласы и модели 2×2×3, не переиспользует L ([PR #75](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/75)).
- Пробковая доска: зазор между футером и нижней кромкой рамы закрыт планкой до внутреннего края ([PR #76](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/76)).
- Новый логотип мода: контейнер с накладной в золотом кольце ([PR #77](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/77)).
- Планшет: чипы редкого и дорогого — один спрайт ◆ (розовый / золотой), тултип чипа с текстом; шапка подробностей icon-only ([PR #78](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/78)).
- Уже на `main` к этому релизу: пробковая доска станции и админ-панель деревни, модель станции «Стойка», Jade-тултипы контейнера и станции, одна станция на деревню.

GameTest **105/105**.

## 0.2.1-beta (30.10.2026)

Патч поверх `0.2.0-beta`. Протокол сети не менялся (`PROTOCOL_VERSION` `"3"`). GameTest **68/68**.

- Исправлено мерцание погон на скинах со вторым слоем: пластина сидит выше оверлея рукава, а не в его плоскости ([PR #66](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/66)).
- Накладная на контейнере смотрит на игрока, который нажал «Опубликовать»: сторона запоминается в заказе и применяется при появлении ящика (`facing` = сторона − 90°). Новых текстур нет; дверь переезжает. Старые заказы без поля и NPC/системные — накладная на востоке, как раньше ([PR #67](https://github.com/Poligorn/MC-AeronauticsCouriers/pull/67)).

## 0.2.0-alpha (30.10.2026)

### Обучение курьера
- При первом открытии планшета без лицензии появляется окно «Курьерская служба»: обучение или пропуск.
- Учебный заказ без награды, залога и срока, +100 XP один раз. Подсказки «Шаг N из 4» есть только в планшете. В мире подсказки идут через action bar, чек-лист — в Профиле и на панели задач.
- Отказ возвращает учебный заказ на доску. Потерянный контейнер снова появляется у точки A.
- В Профиле: «Пройти обучение», «Восстановить лицензию · 25» (новый номер, старый недействителен). Лицензия не выпадает при смерти.
- Админ: «Обучение новых курьеров: Вкл/Выкл» во вкладке «Сервер», команда `/couriers admin server tutorial on|off`.

### Профили залога
- `economy.collateral_profile`: Мирный / Кастомный / Лёгкий / Нормальный (по умолчанию) / Сложный. Меняется во вкладке админа «Экономика». В Мирном залога нет, в Кастомном заказчик задаёт его сам.

### Уведомления и задачи
- Тосты 190×30 с очередью: срочные идут вне очереди, одинаковые сворачиваются в «×N». Тосты скрываются при F1/F3/чате/паузе. По умолчанию в чат идут только срочные.
- Предупреждения о сроке за 5/2/1 мин, просрочка, «контейнер далеко». Сводка «Пока вас не было» при входе.
- Бейджи непрочитанного на планшете в хотбаре и инвентаре, на кнопке инвентаря, на вкладке «Почта» (коралловый при срочных). Точка на «Заказах» — новые заказы.
- Почта: категории, группы, фильтры, «Прочитать все».
- Экран «Уведомления и задачи» в Профиле: настройка каналов по категориям.
- Вкладка «Задачи» и HUD-панель справа (до 4 строк, режимы). Клавиша переключения режима не назначена.
- Конфиг клиента: `[notifications]` и `[tasks]`. Конфиг сервера: `[notifications]`, `[tutorial]`, `[license] restore_price`, `economy.collateral_profile` / `npc_custom_ratio`.

## 0.1.3-alpha (28.10.2026)

### Планшет — UI
- Тонкая гладкая латунная рамка **14 px** (`FRAME_BORDER`), без винтов, пластин и заклёпок; отступ контента **14 px**.
- Антенна: удлинённая мачта, стальная база на верхнем краю; **жёлтый** импульс наружу при отправке (принятие заказа и др.), **голубой** сходящийся импульс при входящем уведомлении (`notification_alert`, ~0.7 с). При `ui_animations=false` — только короткая вспышка лампы.

- Иконки спуров: предметы **Numismatics** через `renderItem`, иначе спрайты `textures/gui/coins/`.

## 0.1.2-alpha (28.10.2026)

### Плейтест
- Исправления рамки/монет/вкладок (промежуточная толстая рамка отменена в 0.1.3).


### Профиль на планшете
- Вкладка «Профиль»: полоса прогресса XP внутри текущего ранга, подпись до следующего ранга, «Максимальный ранг» для V и администратора.
- Пороги XP и минимальная успешность для V берутся из серверного конфига и приходят в снимке доски; после доставки снимок обновляется без переоткрытия окна.
- Тултип на полосе: залог, размер контейнера, дистанция и число активных перевозок следующего ранга.
### Админ-панель на планшете
- Вкладка «Тест» заменена на **«Админ-панель»** (только операторы, permission 2+); подвкладки Заказы / Игроки / Экономика / Сервер.
- Заказы: все активные контракты на сервере, действия spawn/deliver/fail/cancel+refund/extend+30m/tp; разрушительные — с подтверждением.
- Параллельные команды `/couriers admin …` (contract, player, economy, server).
- Перезагрузка datapack `item_values`, `item_weights`, `village_cargo`; мировые override цены/веса предмета; правка части ключей `aerocouriers-server.toml` из GUI.
### Планшет — фильтры списков
- Вкладка «Заказы»: размер S/M/L, «только доступные», тип заказа, сортировка (награда, дистанция, срок, залог) с переключением ▲/▼.
- «Мои · Текущие / История»: фильтры по статусу и роли (курьер / заказчик), сортировка; при фильтрации — «показано X из N» и «Сбросить».
- Состояние фильтров сохраняется между открытиями планшета (клиент).

### Контейнеры M и L
- Блоки `cargo_container_m` (1×1×2) и `cargo_container_l` (2×2×2): те же правила, что у S (ленивый спавн, опечатка, Sable, залог/ранг).
- Заказы выбирают размер S/M/L по весу и числу стаков; на доске и в модалке принятия — метка размера; ранг II/III для M/L.
- Груз больше L → отказ с текстом про будущие мульти-контейнеры (ранг IV+).
- Конфиг `[cargo]`: `slots_*`, `max_weight_*` для каждого размера.

## 0.1.0-alpha (26.10.2026)

### Итерация 6 — ранги и навигация
- Луч-маяк и HUD-компас к точке погрузки/доставки для ваших активных заказов (`aerocouriers-client.toml` → `[navigation]`).
- Временные точки Xaero на погрузку и доставку (📦 по умолчанию); снятие при завершении/выходе.
- Принятие заказа: явные сообщения по лимитам ранга (залог, размер, дистанция, слоты); строки с замком на доске; отказ дублируется в action bar.

### Планшет и доска
- Тёмный фон монитора `#0A0200`, сетка `#241006`, латунная рамка 16 px, отступ контента 9 px, антенна 2× (без шестерни на рамке).
- Вкладка «Мои» разделена на **Текущие** и **История**; исправлено переключение активной вкладки.
- Убрана нижняя строка уведомлений на доске; уведомления — колокол, отдельный экран, action bar и чат (со звуком).
- Принятие заказа через модалку подтверждения с фактическим залогом (стажёр: 0).

### Почтовые станции (итерация 5)
- Окно станции по ПКМ: репутация (уровень, бонус, следующий порог), список NPC-заказов, переименование OP.
- Репутация: пороги и проценты бонуса в `aerocouriers-server.toml` → `[stations]`.
- **Редкий груз** в NPC-заказах: datapack `village_cargo/rare/`, залог по `item_values.json`, иконка на строке заказа.
- Стажировка: первые 3 без залога, лимит дистанции, аванс после 3-й доставки.

### Прочее
