## Продукт и мосты (не GDD §17)

12. **Общая панель задач и тосты.** В 0.2.0-alpha уже есть `task/Tasks`, `TaskPanelHud`, `ClientToasts`, экран «Уведомления и задачи». Бэклог: калибровка, клавиша панели по умолчанию, не дублировать тосты с чатом, сводка «пропущено». Не путать с via-waypoints.
13. **Мост с приватами FTB Chunks / OPAC.** GDD §7.1 / §12: права на погрузку в радиусе 8 бл, иначе предупреждение. `compat/ClaimsBridge` в плане, класса нет. В плоте Sable приватов нет. Только после сверки API, изолированный класс + `ModList`.
14. **Вес из FFItemWeight.** Soft-dep: если мод загружен — вес из него, иначе `item_weights.json`. ⚠️ API не изучен (`api-verification.md`). Мост в `compat/`, не в `Weights` напрямую.
15. **3D-модели погон и предметов через GeckoLib.** `OrderTabletVisuals` — заглушка (`client/tablet/OrderTabletVisuals.java`). Погоны сейчас квады на `PlayerModel`. Не подключать GeckoLib, пока нет моделей и решения по лицензии/версии пака.
16. **Свои текстуры боковин контейнера с накладной.** Сейчас `block/cargo_container_*_waybill.png` — светлая панель; предмет накладной заменён, боковины нет (`STATUS`, `docs/ASSETS.md`). Нужен арт граней S/M/L/XL, не копировать чужие текстуры.
