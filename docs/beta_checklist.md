# Чек-лист бета-плейтеста

Короткий проход полного цикла **Aeronautics Couriers** перед калибровкой конфигов. Записывайте наблюдения в таблицу в конце.

**Сборка:** NeoForge 1.21.1, мод `aerocouriers`, Create + Aeronautics + Sable (как в dev-паке). Язык клиента: переключите RU и EN и убедитесь, что нет «сырого» английского в RU (кроме брендов: Xaero, Curios, Aeronautics Couriers).

---

## Подготовка

- [ ] Лицензия пилота в слоте Curios «Лицензия», планшет заказов (слот или рука).
- [ ] Деньги на счёте (Numismatics или изумруды) — хотя бы 500 сп для P2P-теста.
- [ ] Две почтовые станции в мире (деревня или `/couriers station` + generate) для NPC-маршрута.
- [ ] Сундук с грузом для P2P (накладная + контейнер).
- [ ] Включены зоны (`[zones]`) и навигация (`[navigation]`) в клиентском конфиге.

## Локализация (быстро)

- [ ] RU: кнопки «Тест» OP — «Принудительно создать/доставить», не English.
- [ ] `/couriers contract info` — манифест с «×», минуты «мин», не «min».
- [ ] EN: нет кириллицы в чате/UI мода.

---

## Что записать для баланса

Для **каждого ранга** (хотя бы I, II, III) и типа заказа (NPC / P2P) заполните 2–3 строки:

| Ранг | Тип | Дистанция (бл) | Время (мин) | Награда (сп) | Залог (сп) | Сп/час (оценка) | Заметки |
|---|---|---:|---:|---:|---:|---:|---|
| I | NPC | | | | | | |
| I | P2P | | | | | | |
| II | … | | | | | | |

**Сп/час** ≈ `(награда − залог_риск) / (время_мин / 60)` для успешных доставок подряд (без AFK).

Дополнительно:

- [ ] Среднее время «от accept до deliver» на 500 / 1500 / 4000 блоков.
- [ ] Был ли заказ **невыгоден** (залог + время vs награда)?
- [ ] Редкий груз: заметили иконку, адекватен ли залог по `item_values`?
